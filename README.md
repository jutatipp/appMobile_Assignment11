# Nong Khai POI

แอป Expo React Native สำหรับแสดงตำแหน่งสถานที่สำคัญ (Point of Interest) ในจังหวัดหนองคาย ผู้ใช้สามารถเลือกรายชื่อสถานที่ แล้วแอปจะเลื่อนแผนที่ไปยังตำแหน่งนั้นพร้อมแสดงหมุดและป้ายชื่อ

## ความสามารถของแอป

- แสดงแผนที่แบบเต็มหน้าจอ
- มีรายชื่อสถานที่สำคัญในหนองคาย 10 แห่ง
- เลื่อนรายชื่อสถานที่ในแนวนอนได้
- เมื่อกดเลือกสถานที่ แผนที่จะเลื่อนไปยังตำแหน่งที่เลือก
- แสดงป้ายชื่อสถานที่เหนือหมุดบนแผนที่
- แสดงประเภท อำเภอ และพิกัดของสถานที่ที่เลือก
- รองรับ Android และ iOS

## รายชื่อสถานที่

1. สะพานมิตรภาพไทย–ลาว แห่งที่ 1
2. ศาลาแก้วกู่
3. วัดโพธิ์ชัย
4. ตลาดท่าเสด็จ
5. สวนสาธารณะหนองถิ่น
6. พระธาตุกลางน้ำ
7. พิพิธภัณฑ์สัตว์น้ำจังหวัดหนองคาย
8. วัดพระธาตุบังพวน
9. สกายวอล์ควัดผาตากเสื้อ
10. วัดหินหมากเป้ง

## เทคโนโลยีที่ใช้

- Expo SDK 54
- React Native
- TypeScript
- react-native-maps

## การติดตั้ง

ต้องติดตั้ง Node.js ก่อน จากนั้นเปิด Terminal ที่โฟลเดอร์โปรเจกต์และรัน:

```bash
npm install
```

## การเปิดแอป

เริ่ม Expo Development Server ด้วยคำสั่ง:

```bash
npx expo start
```

หลังจาก Metro แสดง QR code เปิดได้ดังนี้:

- มือถือจริง: เปิด Expo Go แล้วสแกน QR code

มือถือและคอมพิวเตอร์ควรเชื่อมต่อ Wi-Fi เครือข่ายเดียวกัน หากสแกน QR code แล้วเชื่อมต่อไม่ได้ ให้ลอง:

```bash
npx expo start --tunnel
```

## คำสั่งที่ใช้บ่อย

```bash
# เริ่ม Development Server
npm start

# เปิด Android Emulator
npm run android

# เปิด iOS Simulator
npm run ios

# ตรวจสอบ TypeScript
npx tsc --noEmit
```

> หมายเหตุ: ไม่แนะนำให้ใช้ `npm run web` กับโปรเจกต์นี้ เพราะ `react-native-maps` ออกแบบมาสำหรับ Android และ iOS เป็นหลัก

## ไฟล์สำคัญ

- `App.tsx` — หน้าจอหลัก ข้อมูลสถานที่ รายชื่อ และแผนที่
- `app.json` — การตั้งค่าแอป Expo
- `index.ts` — จุดเริ่มต้นของแอป
- `package.json` — dependencies และคำสั่งสำหรับรันโปรเจกต์
