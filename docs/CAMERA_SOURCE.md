# ที่มาของโค้ดกล้อง

ใช้โค้ดที่ผู้ใช้ระบุ: [jutatipp/Photo_camera-_expo](https://github.com/jutatipp/Photo_camera-_expo)

อ้างอิง commit `85e426371ae6abd5ac242ca93a771a82148e967e`

นำ `CameraScreen`, `CameraPermissionScreen`, `PhotoEditorScreen`, `FilterCarousel`, `FilteredCanvas`, `filterPresets` และ design tokens มาปรับไว้ที่ `src/components/camera`

คงหน้ากล้องเต็มจอ ชัตเตอร์ สลับกล้อง หน้าแสดงภาพ และตัวเลือกโทนจากต้นฉบับ เปลี่ยนสีเน้นเป็นเขียวมะนาวของแอป และเปลี่ยนการกดบันทึกจากลงคลังทันทีเป็นบันทึกในอัลบั้มของทริป ผู้ใช้กดบันทึกลงคลังมือถือจากรูปในอัลบั้มได้ภายหลัง

`TripCamera.tsx` รับภาพที่ถ่ายหรือเลือกจากคลัง ลดขนาดด้านยาวสูงสุด 1600 px และใช้ Skia สร้างภาพพร้อมโทนจริง ไม่ใช่เพียง overlay บน preview จากนั้นบันทึก JPEG ขนาดไม่เกิน 3 MB ผ่าน TripContext

ปรับข้อความขอสิทธิ์ให้บอกตามจริงว่ารูปที่บันทึกจะส่งไป API เมื่อเชื่อมต่อได้ ไม่ใช้ข้อความเดิมที่บอกว่ารูปไม่ออกจากเครื่อง กล้องหยุดเมื่อแอปไม่ active และมีปุ่มกลับทริปโดยไม่บังคับอนุญาตสิทธิ์
