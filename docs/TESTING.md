# การตรวจระบบ AppNong Khai Trip_Hybrid_Mobile

ตรวจรอบล่าสุด 25 กันยายน 2026: TypeScript (รวม unused imports), Prettier, tests 8 ชุด และ Metro export iOS/Android ผ่าน ตรวจ Expo config ได้ชื่อใหม่และลิงก์ไฟล์ในเอกสารไม่มีรายการเสีย ผลนี้ไม่แทนการทดสอบบนมือถือจริง

## ขอบเขตการตรวจ

- TypeScript รวม unused imports และ formatting
- ชุดทดสอบ 8 ชุด: API, session, validation, ภาพ, migration, วันกลับและวันว่างระหว่างทริป
- Expo config ต้องใช้ชื่อใหม่และอ้างอิง assets ที่มีอยู่
- Metro export iOS/Android ตรวจ JavaScript/assets ไม่ใช่ native build
- ยังต้องทดสอบมือถือจริง กล้อง คลังภาพ SQLite offline และ notification
- ยังไม่ได้ยืนยัน clean clone/install/run และ native build ของรุ่นนี้

## แบบบันทึก

ระบุชื่อผู้ทดสอบ วันที่ รุ่นอุปกรณ์/OS, Expo Go หรือ Development Build และ commit ที่ใช้ ห้ามทำเครื่องหมายผ่านก่อนทดสอบจริง

## คำสั่ง

```bash
npm run typecheck
npm test
npm run format:check
npx expo-doctor
npx expo export --platform ios --platform android --output-dir /tmp/nongkhai-trip-export
```

API tests ใช้โฟลเดอร์ชั่วคราวและ port สุ่ม ไม่แก้ข้อมูลใน `server/data` ส่วนการทดสอบ clean clone ต้องใช้ repository ที่ push รุ่นนี้แล้ว
